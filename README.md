# RAG-ассистент по документам предприятия

Локальный ассистент на базе LlamaIndex и языковой модели Saiga Mistral 7B.
Отвечает на вопросы по документам предприятия, включая табличные данные, с простой фильтрацией
нежелательных запросов.

▶️ **[Открыть блокнот в Google Colab](https://colab.research.google.com/github/rustam4ike/rag_assistant/blob/main/practice_2.ipynb)**

**Стек:** Python, LlamaIndex, HuggingFace, Transformers, PEFT (LoRA), Docling, PyTorch, Saiga Mistral 7B

## Данные

В качестве данных используется часть моей дипломной работы, еще со студенческой практики.

## Задачи

- Построить RAG-пайплайн по документам предприятия (текст + таблицы)
- Обеспечить релевантные ответы строго по документам, без домысливания
- Добавить простую фильтрацию нежелательных запросов
- Запустить модель с учетом ограничения видеопамяти

## Реализация

1. Загружается модель `IlyaGusev/saiga_mistral_7b` с LoRA-адаптером и 4-битным квантованием
2. Проводится настройка LlamaIndex
3. Строятся векторные индексы с помощью модели `paraphrase-multilingual-MiniLM-L12-v2`
4. Формат `.docx` в папке конвертируются в структуру данных `.md`
5. Загружаются документы предприятия
6. Осуществляется ранжирование найденных фрагментов: ColBERT + LLMRerank
7. Для текстовых и табличных документов используются разные промпты и движки запросов
8. Запрос проходит фильтр → поиск релевантных чанков → ранжирование → генерация ответа

## Результаты

- Ассистент корректно отвечает на вопросы по тексту
- По таблицам выдаёт данные соответствующие запросу
- Простой фильтр блокирует запросы на запрещённые слова
- Модель работает в 4-битном квантовании, что снижает требования к видеопамяти
